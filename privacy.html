Privacy Policy

Last updated: 18 November 2026

Transcript Backup is a private tool operated by Redpoint Studio for its owner's personal use. It asks for access to Google Drive using the drive.file scope only.

What it accesses

With the drive.file scope the tool can see and manage only the files and folders it creates itself. It cannot see any other file in the Google Drive account.

What it stores

Encrypted backup archives, uploaded to a single folder in the owner's own Google Drive. The files are encrypted on the owner's computer before upload, using a passphrase that Google never receives.

Sharing

Redpoint Studio does not collect, sell, share or transfer any Google user data to anyone. The tool has no server, no analytics and no third parties. Authorisation tokens are stored only on the owner's computer.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
